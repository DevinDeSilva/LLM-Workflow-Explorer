In the pipeline, the batch SPARQL Query Extractor receives two inputs: an entity list through its "KG query extraction input port: entities" and a query function via its "KG query extraction input port: query_function". It then invokes its sub‑program – the SPARQL Query Builder – to construct SPARQL queries for each entity using the supplied query function. The resulting queries are executed against the knowledge graph, producing KG knowledge that is emitted through the program’s output port.
