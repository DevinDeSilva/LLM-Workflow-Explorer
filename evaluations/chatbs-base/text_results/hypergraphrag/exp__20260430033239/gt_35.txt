The **SPARQL query function** that feeds into the Batch SPARQL Query Extractor is *not* produced by a generative AI task. It is defined as an input port (`KG query extraction input port: query function`) of the `Batch SPARQL Query Extractor` program, which in turn uses the `SPARQL Query Builder` sub‑program to construct queries from entity specifications. The only component that explicitly states it is generated by a large language model is the **Query Result Post Processor Function Generator** (described as “Generates the post processing Function using Large language models”), which operates after query execution, not during query construction. Therefore, the SPARQL query function itself is not created by an AI generative task.
