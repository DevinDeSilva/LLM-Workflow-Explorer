The **Information Extractor** step in the pipeline is driven by a *function generator* (the “Information Extractor function generator”) that, when executed, emits an **LLM‑Output information extractor** artifact. This output artifact contains a single program entity called **information_extractor**, which itself has two ports: an input port for the text to be processed and an output port that produces a list of extracted entities (the “extracts” data). In other words, the function’s output parameters are the *Information Extractor* program and its resulting list of extracted entities.
