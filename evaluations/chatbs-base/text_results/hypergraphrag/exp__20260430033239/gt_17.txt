| Program | Port(s) involved | How it connects |

**Key point**

The *function* that actually performs the post‑processing is the **LLM‑query_result_post_processor** (a Large Language Model function generated by `Generative_Task-query_result_post_processor`). This function is invoked by the **Query Result Post‑Processor** program, which receives its input through the `kg_knowledge` port connected to the output of the **Batch SPARQL Query Extractor**. Thus, the chain of programs linked via ports for SPARQL query post‑processing consists of:

1. **Data Frame Combiner** → 2. **Batch SPARQL Query Extractor** → 3. **Query Result Post‑Processor** (using the LLM function).
